# battery-data
An experimental repository to make battery data available in interoperable, semantic linked data formats. It includes mostly data generated from the Horizon Europe research project DigiBatt, supplemented with some notable datasets from literature (under CC-BY-4.0 licenses) and cited where appropriate. This repo is under unstable development.
